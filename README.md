An open book on Git for two kinds of readers: people who have never used it, and computer science students who need to use it for real. It follows one small firmware project and one change inside it, from the first line you edit to a tagged release. Every step is shown twice, as a Git command and in Sourcetree, with GitHub as the hosting platform. Each chapter has commit graphs, term and know-how boxes, optional deep dives into how Git works inside, and a hands-on section that uses the practice project included in this repository.

## Reading paths

| Path | What to read |
|---|---|
| 🌱 New to Git | The main text and hands-on sections in order; skip the deep dives |
| 🎓 Computer science students | The whole book in order, including the deep dives |
| 🚀 Start using Git today | Chapters 0, 1, 2, 4 and 6 |
| 👥 Getting ready to join a team | Chapters 6–8 and Appendix B |
| 🚑 Something went wrong | Chapter 9 and Appendix C |

To follow along from any chapter, clone this repository and run `bash practice/setup.sh <chapter>`. It creates a practice repository in the state that chapter starts from.

## Disclaimer

This book is based on public documentation and common practice. It is not affiliated with the Git project, GitHub or Sourcetree.
